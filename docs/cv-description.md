**TeacherLens — Independent educational technology and ML research project**

Built a Russian/English mathematics learning prototype that connects deterministic equation checks with student-selected strategies, targeted practice and follow-up reflection. Implemented an original 24-problem bank, exact rational validation, editable plans and browser-local progress using Next.js and TypeScript. Preserved reproducible Python ML research with question-grouped evaluation; documented the classifiers' limitations and kept them out of authoritative student diagnoses.
